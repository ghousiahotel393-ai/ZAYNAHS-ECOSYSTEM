# 336. DATABASE ARCHITECTURE

The database must be local-first.

Each device has its own local database.

Example:

    Device A → Local DB
    Device B → Local DB
    Device C → Local DB
    Windows → Local DB
    Web → Supported local/remote persistence strategy

There is NO branch architecture.

There must be NO:

    branch_id
    branch table
    branch manager
    branch-scoped permissions
    branch-scoped reports
    branch switching
    branch inventory

A device is a trusted peer, NOT a branch.

---

    Authoritative Records
    Projections
    Cache
    UI State

    immutable inventory movements
    sales

    payments
    wallet transactions
    expenses
    customer/supplier financial events
    sync events
    audit events

Projection/cache:

    inventory_balances
    dashboard totals
    calculated report indexes
    derived balances

    rebuild from authoritative records

Never blindly overwrite the authoritative ledger to fix a projection.
