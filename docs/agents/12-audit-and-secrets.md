# AGENTS — AUDIT TRAILS & ABSOLUTE BAN ON SECRETS IN LOGS

# 79. AUDIT

Audit sensitive operations.

Minimum:

    sale
    return
    replacement
    inventory adjustment
    price change
    discount override
    product edit
    permission change
    role change
    device pairing
    device revoke
    backup
    restore
    recording protect
    recording delete
    sync conflict

---

# 80. NEVER LOG SECRETS

Never log:

    passwords
    private keys
    API secrets
    access tokens
    refresh tokens
    encryption secrets
