# AGENTS — DEVICE TRUST LIFECYCLE & PAIRING

# 66. DEVICE TRUST

Trust states:

    PENDING
    TRUSTED
    REVOKED
    BLOCKED

Pairing requires:

    discovery
    authentication
    explicit confirmation
    identity exchange
    trust creation
    audit

---

# 67. NO AUTO TRUST

Being on:

    same Wi-Fi

does NOT automatically mean:

    trusted device

---

# 68. REVOKED DEVICE

Revoked device must:

    lose trusted sync ability
    fail new trusted sessions
    have relevant sessions invalidated
    remain auditable
