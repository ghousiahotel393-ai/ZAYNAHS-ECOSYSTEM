# PHASE 03 — USERS & ROLES DATA MODEL

## ROLE HIERARCHY
- **Owner**: Full ecosystem authority, device pairing, security root, backups.
- **Admin**: Operational management, staff roles, settings.
- **Manager**: POS, reports, CCTV monitoring, inventory adjustments.
- **Cashier**: Sales checkout, returns (if permitted), register drawer.
- **Salesman**: Product search, customer orders, cart creation.
